### 🗄️ Core Folders & Responsibilities
*   **`Zonek/`**: Houses the primary customer-facing React SPA frontend (Vite-based) and the core Node.js Express backend (`Zonek/backend`) managing user records, upvotes, and social communication.
*   **`Zonek/frontend/`**: An orphaned frontend project using custom routing and Firebase Authentication, currently unused.
*   **`zonek-orchestrator/`**: Implements the Server-Sent Events (SSE) research route. Gathers data concurrently from scrapers, generates the AI report, and executes the verification firewall.
*   **`Zonek_browser/`**: Handles Perplexity-style neural web search (Tavily/Exa/Serper) and scrapes webpage markdown via Jina Reader, extracting facts using a local LLM call.
*   **`Zonek_gov/`**: Periodic daemon script loading Indian Census data, open weather records, Jal Jeevan water progress, crop prices, and local infrastructure projects into a local MongoDB database.
*   **`india_rental_scraper/`**: Python FastAPI service utilizing `curl_cffi` and `playwright` to scrap commercial properties from 8 Indian rental listing portals.
*   **`Zonek-Intelligence/`**: Runs the operational console dashboard and Chrome extension helper scripts for manual list scraping (Justdial extraction scripts, etc.).

### ⚠️ Placeholders & Hardcoded Blocks
*   **Static Chat Responders**: Peer-to-peer message exchanges in [Collaboration.tsx](file:///d:/my%20projects/my%20projects/Zonek_Main/Zonek/components/Collaboration.tsx) are simulated. When a user sends a message, a `setTimeout` triggers a standard reply (*"Thanks for your message! I'll get back to you shortly."*) instead of storing and loading active chats from the database.
*   **Maps & Heatmaps**: Visual maps representing rental costs or competitor clusters utilize static graphical cards and mock overlays rather than dynamic geospatial data points (e.g. Leaflet/Google Maps shapes).

### 📈 Overall Frontend Completion: **85%**
*   *Justification*: The entire bento grid user interface, multi-step listing workflows, detail modals, profile editing, and research progress dashboard are fully built, responsive, and styled. The remaining 15% consists of placeholders for the maps and simulated peer-to-peer chat responders. The disconnected `Zonek/frontend/` sub-directory is completely unused and orphaned.

## 9. CRITICAL GAPS

1.  **No Auth on File Deletion (Security Vulnerability)**: The endpoint `DELETE /api/images/:fileId` has no authentication check. Anyone can delete any image file stored in the GridFS database by sending a request with the file ID.
2.  **Websocket Wildcard CORS**: Socket.io permits connections from any origin (`origin: "*"`), creating cross-origin vulnerability risks in production.
3.  **No Premium Proxy Rotation**: Under real user search loads, scrapers will get blocked quickly by rental portals.
4.  **Fragmented Database Architecture**: The project uses four separate databases (`bridgehead`, `zonek_gov`, `zonek_browser`, `zonek`) on localhost, making deployment and data synchronization complex.
