# ⚙️ Zonek-Machine — Background Extraction & Intelligence Microservices

> **Role in Platform:** The autonomous data harvesting, web scraping, and evidence orchestration engine for Zonek.  
> **Status:** Active Data Pipeline (Target Beta: Dec 15, 2026 | Launch: Jan 2027)

---

## 🏗️ Architecture & Sub-Engine Breakdown

Zonek-Machine consists of **4 specialized services**:

```
Zonek-Machine/
├── orchestrator/          # Express.js API Gateway & SSE Pipeline Coordinator
├── gov-data/              # Government, Census & Civic Data Harvester
├── browser-intel/         # Deep Web Extraction & Fact Verification
└── rental-scraper/        # Python/FastAPI Commercial Real Estate Scraper
```

---

## 1. `orchestrator/` (The Research Pipeline Coordinator)

### What Actually Exists Today:
- **API Entrypoint (`src/index.ts`):** Express server exposing `/api/v1/research` with SSE (Server-Sent Events) streaming.
- **Pipeline Execution (`src/pipeline/orchestrator.ts`):** Triggers parallel data collection from the other 3 engines using `Promise.allSettled`.
- **Adapters:**
  - `rentalAdapter.ts`: Connects to `rental-scraper` (Port 8000).
  - `govAdapter.ts`: Connects to civic datasets and Supabase.
  - `browserAdapter.ts`: Connects to `browser-intel` (Port 8003).
- **Intelligence Packet Normalizer (`src/normalizer/intelligencePacket.ts`):** Merges outputs into a unified JSON evidence packet tagged with source, confidence, and timestamps.
- **Deterministic Hallucination Firewall (`src/normalizer/firewall.ts`):** Verifies that claims generated by LLMs are backed by verified scraped packet facts.

- [ ] Implement local Redis / memory TTL caching (72h for rentals, 30 days for competitors, 90 days for gov data).

## 2. `gov-data/` (Civic & Government Subsidy Engine)

### What Actually Exists Today:
- **Scheduler & Fetchers (`src/index.ts`, `src/orchestrator.ts`):**
  - `weather.ts`: OpenMeteo API integration for district temperature, rainfall, and climate data.
  - `agmarknet.ts`: Agricultural mandi prices and commodity arrival volumes.
  - `infrastructure.ts`: Jal Jeevan Mission (water), PMAY (housing), and infrastructure development data.
  - `census_2011_districts.csv`: LGD (Local Government Directory) code mappings.
  - `seed_schemes.js`: Supabase seeder for Central/State MSME schemes (Mudra, PMEGP, Stand-Up India).
- **Database Target:** Successfully connected and writing to Supabase tables: `gov_districts`, `gov_weather`, `gov_schemes`, `gov_crop_prices`.

## 3. `browser-intel/` (Deep Web & News Intelligence)

### What Actually Exists Today:
- **Search Connectors (`src/search/`):** Integrations with Tavily and Exa.ai API engines for neural and keyword searches.
- **Web-to-Markdown Extractor (`src/extractor/`):** Strips HTML boilerplates and converts target news, municipal notices, and local blogs into clean markdown.
- **Fact Normalizer (`src/normalizer/`):** Uses Groq to extract high-confidence claims (e.g., local infrastructure road widening, new commercial zoning, competitor footfall trends).

### What Happens Next (Sprint Action Items):
- [ ] Add structured error handling when external search API quotas are exhausted.
- [ ] Pre-cache news and regulatory changes for flagship launch hubs (Bangalore, Mumbai, Delhi-NCR).
- [ ] Feed localized micro-market news directly into the *Micro-Location & Rentals* report tab.

## 4. `rental-scraper/` (Commercial Property Scraper)

### What Actually Exists Today:
- **FastAPI Core (`api.py`, `main.py`):** Python service exposing commercial rental lookup endpoints on Port 8000.
- **Scraper Modules (`scrapers/`):**
  - `magicbricks.py`: Commercial office, shop, and showroom listings with square footage, floor, and monthly rent.
  - `olx.py`: Peer-to-peer retail and commercial rental space listings.
- **Rate Limiter & User-Agent Rotator (`core/rate_limiter.py`, `utils/user_agents.py`):** Anti-bot protection with randomized request headers.
- **Supabase Exporter (`utils/supabase_handler.py`):** Automatically maps scraped commercial properties into the `rental_posts` table.

### What Happens Next (Sprint Action Items):
- [ ] Add 99acres commercial scraper adapter for enhanced Bangalore and Mumbai commercial density.
- [ ] Implement locality resolver cache (`resolvers/locality_cache.json`) to map user street names to portal search slugs in sub-10ms.
- [ ] Pre-populate 500+ commercial spaces across Bangalore (Indiranagar, Koramangala, HSR, Whitefield) and Mumbai (Bandra, BKC, Andheri) ahead of the December 15 beta.
